# 📱 WhatsApp Auto Message Sender

This is a simple Python script that automatically sends messages on WhatsApp.

## 🚀 Features
- Sends messages repeatedly
- Custom message support
- Adjustable delay
- Easy to use

## 🛠 Requirements
- Python installed

## 📦 Installation
pip install -r requirements.txt

## ▶️ Usage
1. Run:
   python auto_message.py

2. Open WhatsApp chat within 10 seconds

3. Messages will start sending automatically

4. Press CTRL + C to stop
